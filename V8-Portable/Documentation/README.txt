POS Desktop Application - Version 8
=====================================

HOW TO RUN
----------
1. Make sure Node.js 18+ is installed (https://nodejs.org/)
2. Double-click start.bat
3. App opens at http://localhost:3000/ar

WHAT IT INCLUDES
----------------
- POS: Products, invoices, point-of-sale interface
- Arabic (RTL) interface
- SQLite database (portable, no server required)
- Printer support (receipts, barcodes)
- License management
- REST API on port 3001

SYSTEM REQUIREMENTS
-------------------
- Windows 7, 8, 10, or 11
- Node.js 18 or later
- Any modern browser (Chrome, Firefox, Edge)
